# Assignment 03 — MLOps AI Agent

An AI agent (Gemini tool calling) that answers questions about and operates an ML system built on
DVC, MLflow, Apache Airflow 3 and Kubernetes.

## Environment

- Python 3.12 via [uv](https://docs.astral.sh/uv/); dependencies pinned in `uv.lock`.
- Airflow 3.4 runs in its **own** venv (its constraint pins clash with MLflow); DAG tasks call the
  project venv's Python.
- Kubernetes: colima (k3s, docker runtime), so locally built images are visible to the cluster.
- Heavy local state lives outside the repo under `$DATA_ROOT` (on the dev machine an external SSD):

| Path under `$DATA_ROOT` | Contents |
|---|---|
| `venv/` | project venv (`.venv` is a symlink to it) |
| `venv-airflow/` | Airflow venv |
| `uv-cache/` | uv download cache |
| `dvc-cache/`, `dvc-remote/` | DVC cache and the default DVC remote `ssd` |
| `mlflow/`, `airflow/` | MLflow store, `AIRFLOW_HOME` |

### Setup

```bash
cp .env.example .env            # then fill in GEMINI_API_KEY etc.
set -a; source .env; set +a
mkdir -p $DATA_ROOT/venv && ln -sfn $DATA_ROOT/venv .venv
uv sync
uv venv --python 3.12 $DATA_ROOT/venv-airflow
VIRTUAL_ENV=$DATA_ROOT/venv-airflow uv pip install "apache-airflow==3.4.0" \
  --constraint https://raw.githubusercontent.com/apache/airflow/constraints-3.4.0/constraints-3.12.txt
.venv/bin/dvc cache dir --local $DATA_ROOT/dvc-cache
.venv/bin/dvc remote modify --local ssd url $DATA_ROOT/dvc-remote   # only if your path differs
.venv/bin/dvc pull
```

## Data (DVC)

`data/dataset.csv` is the sklearn breast-cancer dataset (binary `target`), generated by
`training/make_dataset.py`. Versions are git tags:

| Tag | Rows |
|---|---|
| `data-v1` | 400 |
| `data-v2` | 569 |

Reproduce an older version:

```bash
git checkout data-v1 -- data/dataset.csv.dvc && .venv/bin/dvc checkout
```
